# Tickets

Local ticket workspaces for Ship Happens (Auto RFP sheet Filler).

## Convention

```
.project/tickets/
  SB-XXXX/
    README.md      # goal, AC, plan
    notes.md       # optional working notes
```

1. Pick an item from [`.project/todo`](../todo/README.md).
2. Create `.project/tickets/SB-XXXX/` and flesh out the plan.
3. Implement in the repo; when done, move/check off the todo and optionally archive under `.project/done/`.

Linear remains the source of record for status sync; this folder is for local execution.
